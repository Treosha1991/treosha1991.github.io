Privacy policy

Effective 10 November 2026

Viral Physics Publisher is a personal desktop utility operated by the owner of the connected YouTube channels. Contact: theeasyexp@gmail.com.

Information used by the utility

  • Google OAuth access and refresh tokens used to authorize the connected YouTube channel.
  • The channel's ID and name, used to confirm the upload destination.
  • Prepared local video files and their titles, descriptions, tags, language and visibility settings.
  • The uploaded video's ID, processing status and metadata returned by YouTube, used to verify the upload and avoid duplicate submissions.

Purpose of access

The utility uses the YouTube upload permission to send explicitly queued videos. It uses read access to check the connected channel and inspect the videos it uploads. These permissions are not used to read Gmail, Google Drive files or contacts. The current utility does not provide a video-deletion operation.

Storage and transfers

OAuth credentials and resumable-upload session information are encrypted on the owner's Windows computer with Windows user-bound DPAPI. Source videos, publishing metadata and upload receipts are stored in the local project directory; those working files are not encrypted by the utility.

When an upload is requested, the selected video and its metadata are sent directly to Google's YouTube API. Token exchanges and refresh requests are sent to Google's OAuth endpoints. This documentation website does not receive the utility's credentials, video files or upload records.

Other uses of Google data

The uploader does not sell Google user data, use it for advertising, send it to an AI model or use it to train a model. Its access and use of Google API information follow the Google API Services User Data Policy, including the Limited Use requirements. Separately authorized development or backup tools may access local project files according to the owner's settings.

Retention and control

Working files and upload receipts remain locally until the owner removes them. Upload receipts retain the destination and YouTube video ID so the utility can recognize a completed submission. Uploaded content remains subject to YouTube's own storage and deletion controls.

The owner can stop the local queue worker and revoke the application's access through Google Account connections. Local copies of credentials and records can then be deleted from the project. To remove a video already uploaded to YouTube, use YouTube Studio.

This documentation website

These pages contain no analytics code or advertising. The hosting provider's own privacy rules apply to normal requests for this website. Google and YouTube process information under their privacy policy.

Questions

Contact theeasyexp@gmail.com about the application's use of data or this policy.
