Viral Physics Publisher uploads locally generated physics and kinetic animations, together with their titles, descriptions and hashtags, to the project owner's YouTube channels.

This is an owner-operated utility. This website provides information about the application; it does not offer account registration, accept videos or receive OAuth tokens.

Choose a channel

Each connection is checked against its expected YouTube channel ID before any video is sent.

Send a prepared video

The desktop utility checks the reviewed MP4 and processes an explicitly queued upload with the selected visibility.

Google and YouTube access

The application requests permission to view the connected YouTube account and manage its videos. It uses that access to confirm the channel, upload prepared videos and verify their processing status. The current utility does not include video-deletion functionality.

Local operation

The upload queue and working files remain on the owner's Windows computer. OAuth credentials are protected with Windows user-bound encryption. Video files are transferred directly to Google's YouTube API.

Read the privacy policy for data handling and access-revocation information, and the use terms for the utility's intended use.
